# Task Manager Web Application

A simple task manager built with HTML, CSS, and JavaScript to help you add, view, complete, and delete daily tasks without reloading the page.

## Technologies used

- HTML
- CSS
- JavaScript

## Steps to run the project

1. Open the project folder in your code editor.
2. Open `index.html` in a web browser.
3. Use the input field to add a new task.
4. Mark tasks complete using the checkbox or delete tasks with the remove button..
